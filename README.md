# Pandit Krishna Astrology – Website

Static website for https://panditkrishnaastrology.com, hosted on Hostinger.

- `index.html` – the whole site (home, Panchang, booking, contact, legal pages)
- `i18n.js`, `lang-*.js` – language switcher and translations
- `panchang-data.js` – daily Panchang data (updated automatically each night)
- `blog-data.js` – daily teaching points
- `.htaccess` – security headers, HTTPS and caching rules
- `img/`, `favicon.ico` – icons and share image

Files in this repository are deployed as-is to `public_html`.
